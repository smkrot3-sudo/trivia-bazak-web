# טריוויה בזק - תוכן המשחק (Web)

זהו תוכן המשחק עצמו (HTML/JS/CSS) של [טריוויה בזק](https://github.com/smkrot3-sudo/trivia-bazak),
מתארח כאן כדף GitHub Pages ציבורי כדי שהאפליקציה תוכל לטעון אותו ישירות מהרשת.

**חשוב:** כל שינוי שנדחף (push) לענף `main` כאן מתפרסם אוטומטית תוך דקה-שתיים
בכתובת https://smkrot3-sudo.github.io/trivia-bazak-web/ - וכל מי שפותח את אפליקציית
טריוויה בזק (עם חיבור לאינטרנט) מקבל את הגרסה המעודכנת באופן מיידי, **בלי צורך בהתקנת
APK חדש**.

מאגר זה ציבורי ואינו מכיל מידע רגיש - המפתח (`config.js`) מכיל רק מפתח Supabase
ציבורי (publishable key) שמיועד לשימוש בצד הלקוח.

מקור ה-APK האנדרואידי, כולל מפתח החתימה, נמצא במאגר הפרטי
[trivia-bazak](https://github.com/smkrot3-sudo/trivia-bazak). עותק מקומי של תוכן זה
מצורף גם שם (ב-`app/src/main/assets/www/`) כגיבוי אופליין למקרה שאין אינטרנט.
